Mahbub - Motion Designer Portfolio

Run in VS Code:
1. Unzip and open the folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension.
3. Right-click index.html > "Open with Live Server".
(Or double-click index.html. Internet is needed for Google Fonts.)

Files: index.html, style.css, script.js, assets/avatar.png
